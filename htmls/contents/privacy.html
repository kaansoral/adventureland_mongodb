นโยบายความเป็นส่วนตัวนี้อธิบายว่าข้อมูลของคุณถูกใช้และจัดเก็บโดย จตุรธาตุ

จตุรธาตุ ใช้คุกกี้สำหรับการยืนยันตัวตนและการตั้งค่า คุกกี้ถูกจัดเก็บระหว่าง HTTP และ HTTPS

ด้วยความต้องการของผู้เล่นและข้อจำกัดทางเทคนิค เกมสามารถเล่นได้ทั้ง HTTP และ HTTPS บน HTTP หากคุณอยู่ในเครือข่ายที่ไม่ปลอดภัย ข้อมูลของคุณอาจถูกเปิดเผย หากเล่นเกมจาก Steam หรือ Mac App Store เกมจะใช้ HTTPS โดยค่าเริ่มต้น

จตุรธาตุ ใช้ Google Analytics สำหรับสถิติ

จตุรธาตุ ใช้ Cloudflare เพื่อความปลอดภัยและการกรอง ข้อมูล HTTP/S เกือบทั้งหมดผ่าน Cloudflare ดังนั้นพวกเขาอาจเข้าถึงข้อมูลทุกอย่างที่คุณให้

จตุรธาตุ ใช้ข้อมูลตำแหน่งของคุณเพื่อพิจารณาว่าเซิร์ฟเวอร์เกมใดอยู่ใกล้คุณโดยรวม

จตุรธาตุ จัดเก็บรหัสผ่านที่เข้ารหัส ตัวละคร ชื่อตัวละคร ข้อมูลที่คุณให้ IP ของคุณ (ใช้สำหรับตรรกะข้อจำกัดตัวละคร) การกระทำของตัวละคร และมีบันทึกและสำรองข้อมูลเหล่านี้อยู่ ณ ตอนนี้ยังไม่มีระบบลบบันทึกและข้อมูลสำรองเหล่านี้ แต่เนื่องจากพื้นที่จัดเก็บคลาวด์แพงมาก ฉันอยากเริ่มลบมันในอนาคต แต่ยังไม่มีเวลา

จตุรธาตุ ไม่มีวิธีส่งอีเมลที่เชื่อถือได้ ดังนั้นเป็นหน้าที่ของผู้เล่นในการติดตามนโยบายความเป็นส่วนตัวนี้ แต่แก่นหลักจะไม่มีวันเปลี่ยน จตุรธาตุ is a game with no intention of misusing a players data

ฉันเป็นนักพัฒนาเกมอิสระที่พยายามอย่างเต็มที่เพื่อปกป้องผู้เล่นและตอบสนองความต้องการ แต่เราอยู่ในโลกที่วุ่นวาย หากคุณเป็นผู้เล่นทั่วไปที่อ่านข้อความนี้ กรุณาระวัง แม้ฉันจะทำทุกอย่างเพื่อปกป้องคุณและข้อมูลของคุณ (โดยเฉพาะหลังจากทุกสิ่งที่ฉันประสบตั้งแต่เปิดเกม ซึ่งทำให้ฉันเติบโตทั้งในฐานะนักพัฒนาและมนุษย์ อย่างน้อยก็หวังเช่นนั้น) ไม่มีอะไรปลอดภัยบนอินเทอร์เน็ต ควรคำนึงถึงข้อเท็จจริงนี้เสมอ
