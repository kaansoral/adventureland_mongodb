1. Create a token

Sign in here, create a token below, and copy it while it is visible. The token starts with mcp_.

2. Paste it in VS Code

Open Command Palette and run Adventure Land: Set API Token. Paste the token there. This works in Cursor too.

3. Activate a folder

Run Adventure Land: Activate Auto Sync Folder. Choose any local folder you want VS Code to manage.

4. Edit and save

The extension downloads every CODE slot. Saving a managed file uploads it back to Adventure Land.

Same idea as /codes

The extension creates an adventureland folder with codes, characters, libraries, and clash inside it. It also keeps history beside that folder.

On activation it downloads every CODE slot. After that it checks for remote changes, uploads offline edits when safe, and uploads managed files when you save them.

Saving from VS Code does not spend Shells and does not start Mainframe by itself.

File names

						
Managed CODE files use name.slot.js. Examples: farm.1.js, merchant.12.js, pvp.Warrior.js. The slot before .js decides where the file uploads. Files in libraries are read-only helpers from the game.
