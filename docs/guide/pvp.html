PVP & Duels

There are three different fights between adventurers: open PVP, safe PVP maps, and private duels. Check which one you are entering before you attack.

Open PVP
On a PVP server—or an ordinary PVP map—other adventurers can attack you. Defeat can cost gold and experience. Items marked with ^ can also drop.
Safe PVP
Some PVE-server arenas allow fighting without the ordinary gold and experience loss. The map, not its appearance, decides the rule.
Duels
A private duel moves both leaders—and their parties—into Duelland. Duel defeat does not use ordinary PVP loss.
Before Entering

in_pvp() reports whether your character is presently exposed. server.pvp tells you whether the whole server is PVP, while G.maps[character.map].pvp describes the current map.

A safe room can still exist on a PVP server. Your party and team are protected from ordinary friendly fire, but strangers are not. Store spare gold and inspect every ^-marked item before leaving safety.

The PVP board records the realm's latest defeats. The Token of Honor collector beside the arena shows the current token exchanges.
Starting a Duel
  1. Both leaders must be online, outside PVP, and not already dueling.
  2. Challenge the other leader. They accept while the challenge is still live.
  3. The two leaders enter immediately. Online party members receive an invitation to the same duel.
  4. Party members enter before the duel begins. Each side spawns as a separate team.

Manually, use /challenge CharacterName, then accept the incoming challenge button. Party leaders challenge for their current parties.

CODE

The duel functions settle only after the server has accepted each step. Challenge and duel invitations are also character events.

character.on("challenge", function (name) { game_log(name + " challenged you"); }); character.on("duel", function (duel) { // Invited party members can join before the fight starts. enter_duel(duel.id).catch(show_json); }); async function challenge(name) { await send_duel_challenge(name); game_log("Challenge delivered to " + name); } async function recent_pvp() { var history = await get_pvp_history(); show_json(history.list); // [winner, defeated] }

The receiving leader uses accept_duel_challenge. See also send_duel_challenge, enter_duel, and get_pvp_history.
