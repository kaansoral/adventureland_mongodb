Crafting & Dismantling

Crafting follows a recipe: bring its exact items, levels, quantities, and gold to the named craftsman. Dismantling is a separate recipe and returns only the materials shown in its own preview.

Craft One Recipe
1. Inspect the resultSelect the item you want to make. A level printed beside an ingredient is required; a different level does not count.
2. Gather exact stacksQuantities may come from one stack in the automatic routine. Combine split stacks before using auto_craft().
3. Visit the right specialistLeo handles ordinary work. Some recipes name another NPC, and both the panel and CODE require that specialist nearby.
4. Leave one spaceThe ingredients and gold are consumed only when crafting succeeds. Keep room for the finished item.
Dismantling Is Not Undo

Open Leo's dismantling service and inspect the result before committing the item. Some returns are fractional chances, and an ingredient used to craft an item is not automatically returned.

For this example, the dismantle recipe returns the fire essence—not the original blade. Leo can also split many leveled compound accessories into three lower-level copies; his panel shows the current cost and requirements.

Craft and dismantle both consume inputs. Locked items are refused. Read the visible result, cost, and free-space warning immediately before confirming.
CODE

auto_craft finds the required inventory stacks. craft is useful when you need to choose the exact inventory positions yourself.

async function make_fireblade() { var blade = locate_item("blade"); var essence = locate_item("essenceoffire"); if (blade === -1 || essence === -1) { game_log("Missing a blade or Essence of Fire"); return; } // The nine arguments fill Leo's grid from top-left to bottom-right. var result = await craft(blade, essence, null, null, null, null, null, null, null); show_json(result); } // If the required quantities already exist in suitable stacks: // await auto_craft("fireblade"); make_fireblade().catch(function (error) { game_log(error.reason || error.message || "Crafting could not start"); });

Recipes are available in G.craft. This logs the live recipe without risking an item:

show_json(G.craft.fireblade); async function dismantle_fireblade() { var slot = locate_item("fireblade"); if (slot === -1 || character.items[slot].l) return; show_json(G.dismantle.fireblade); // Remove the comment only after inspecting the recipe above. // show_json(await dismantle(slot)); }
