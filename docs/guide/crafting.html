MAKING AND UNMAKING
Crafting & Dismantling

Recipes turn materials, items, and gold into something new. Dismantling follows the road back and returns the ingredients shown by its recipe.

Manual

Visit Leo for ordinary recipes, or the specialist named by a recipe. Select the result to inspect its ingredients and cost, place the ingredients in the crafting grid, and craft with enough free inventory space.

Use Leo's dismantling service only after checking the preview. Some dismantle returns are uncertain. Leo can also split many leveled compound accessories into three lower-level copies; the service shows its current cost and requirements.

CODE

Use craft when you want to choose the nine grid positions yourself. auto_craft finds ordinary single-stack ingredients for a named recipe.

async function crafting_example() { await auto_craft("computer"); // The nine arguments are the crafting grid, // from top-left to bottom-right. await craft(null, 0, null, null, 1, null, null, 2, null); // Dismantle the item currently in slot 0. await dismantle(0); }

Reference: dismantle. Recipes are available in G.craft and G.dismantle.

auto_craft needs each requested quantity in one inventory stack. Move or combine stacks first when necessary.
