ROADS, DOORS, AND STRANGE PLACES
Travel & Instances

Adventure Land has roads, transporters, doors, town teleports, and private instances. They do not all follow the same rules.

Manual

Walk to a door and use it, or speak with a transporter such as Alia. The town button channels a return to town and can be interrupted. Some dungeons require a key to create an instance.

For keyed party dungeons, one member can open the instance and the others can enter that same instance while a party member remains inside. Instances do not remain alive forever when nobody is inside and online.

CODE

smart_move plans a route. transport and use_nearest_door use a nearby route point; they do not first walk you there.

async function travel_example() { await smart_move("bank"); await town(); // Use a nearby map door. await use_nearest_door(); // Create or enter a named instance. await enter("crypt"); await enter("crypt", character.in); }

References: smart_move, transport, town, use_nearest_door, enter, leave.

Await travel routines before issuing the next step. Starting a different route interrupts the active smart_move.
Active portals are covered in Events and Home Servers.
