Events & Home Servers

The realm clock, event buttons, and live server state describe what is happening now. Your home server is a separate account choice used for that realm's home rewards.

ScheduleOpen the clock to inspect planned events and their current realm timing.

BeanSets the current eligible realm as your home after showing the long change cooldown.
FavoréShows the Shell cost and remaining time before blessing the current server.

Events Enter in Different Ways
Joinable eventSome server activities accept join(name) and place you into their event map or queue.
World creatureA live boss may need ordinary travel to the coordinates in server.status.
Portal or NPCSeasonal events may begin through a visible portal, turn-in, or local interaction.
Scheduled windowThe clock can announce an event before it is available. Read its guide and live state before acting.
An event name appearing in G.events proves only that the event is defined. Check server.status for the current realm before trying to join or travel.
Home and Blessings

Speak with Bean while on the eligible realm you want to call home. Changing home has a long cooldown, so read his confirmation instead of using it as ordinary travel.

Favoré's blessing is realm-wide and spends Shells. Her panel shows the exact current cost and remaining blessing time. This is separate from setting a home server.

CODE: Read Before Acting
function report_live_events() { for (var name in server.status) { var state = server.status[name]; if (state && (state.live || state.spawn || state.end)) { game_log(name + " is active or scheduled"); } } } report_live_events(); show_json(server.status);
async function join_goobrawl_if_live() { if (!server.status.goobrawl) return game_log("No Goo Brawl here"); await join("goobrawl"); } // These change account or realm state; call them only beside the NPC. // await set_home(); // await bless_server(); // Spends Shells. join_goobrawl_if_live().catch(show_json);
