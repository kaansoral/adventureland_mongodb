THE WORLD KEEPS MOVING
Events & Home Servers

The clock, live server state, and event notices tell you what is happening now. A home server records where each character belongs and is used for that server's home rewards.

Manual

Open the clock at the bottom-left to inspect the schedule. Live events may appear as join buttons, portals, creatures, or NPC interactions; follow the event's own guide because not every event is entered the same way.

Speak with Bean to make the current eligible server your home. Changing home has a long cooldown. Favoré can bless the current server with shells; her interface shows the exact cost and remaining blessing time before you confirm.

CODE

server.status is the current replaceable snapshot of live server state. G.events contains static event definitions.

async function event_example() { show_json(server.status); show_json(G.events); if (server.status.goobrawl) { await join("goobrawl"); } await set_home(); // await bless_server(); // Spends shells: inspect the reference first. }

References: join, set_home, bless_server.

Only call join for a currently available, joinable event. Many world events are reached by travel instead.
