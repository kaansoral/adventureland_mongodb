Exchanges & Quests

Some items are not ordinary loot to equip or sell. Their tooltip marks them for an exchange, a token shop, or a particular NPC.

Manual

Read the item tooltip for the required quantity, then visit its exchange NPC. Xyn handles many boxes and bundles; other treasures belong to specialist collectors. Place the complete stack in the exchange slot and leave inventory room for the result.

Token shops are more direct: inspect the offered reward, its token cost, and the quantity before confirming. Recipes, exchanges, and ordinary NPC errands are different systems even when they use the same materials.

CODE

Stand near the correct NPC. exchange waits for the timed exchange and returns the reward.

async function exchange_example() { var box = locate_item("armorbox"); if (box !== -1) { var result = await exchange(box); game_log("Received " + result.reward); } // Buy a named reward with a named token. await exchange_buy("funtoken", "confetti"); }

References: exchange, exchange_buy, locate_item.

The required stack size and reward pool belong to the item data. Check the live tooltip instead of hard-coding an old requirement.
