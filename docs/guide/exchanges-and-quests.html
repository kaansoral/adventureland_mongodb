Read the Tooltip First
Exchange itemThe tooltip shows the required stack. The result may be fixed or drawn from a reward pool.
Token shopThe NPC shows each named reward and exact token cost. You choose the result before paying.
Quest materialA named collector may require several kinds of material or a particular item level.
Seasonal turn-inThe NPC may exist only while its event is active. Keep the item if its collector is away.

Recipes, exchanges, and quests are different systems even when they use similar materials. A recipe appears in G.craft; an exchange item carries its exchange requirement; a quest follows its NPC's own panel.

The exchange begins only with a complete eligible stack and enough free inventory space. Do not move the item or start another exchange while its progress bar is running.
CODE: Exchange an Item
async function exchange_armor_box() { var slot = locate_item("armorbox"); if (slot === -1) return game_log("No Armor Box found"); var item = character.items[slot]; var needed = G.items[item.name].e || 1; if ((item.q || 1) < needed) { return game_log("Need " + needed + " boxes in one stack"); } var result = await exchange(slot); game_log("Received " + result.reward); } exchange_armor_box().catch(show_json);
CODE: Buy with Tokens
async function buy_confetti() { var price = G.tokens.funtoken.confetti; game_log("Confetti token price: " + price); if (quantity("funtoken") < price) return; await exchange_buy("funtoken", "confetti"); } buy_confetti().catch(show_json);

References: exchange, exchange_buy, locate_item, quantity.
