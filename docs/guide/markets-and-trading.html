WishlistName the item and level you will accept, the quantity wanted, and the gold paid for each. This is a buy order, not a sale.

Stay openThe character's stand must remain open for its listings to operate. Close it when you are done managing the market.
Buying from Another Player

Stand nearby and open the player's merchant panel. Re-read the item name, level, special properties, quantity, and total. A CODE trade includes the listing's current ID so a changed or replaced offer is refused instead of silently buying something else.

Prices are per unit. Before confirming a stack purchase, multiply the visible unit price by the quantity and make sure your inventory can receive it.

async function open_example_shop() { await open_stand(); var staff = locate_item("staff"); if (staff !== -1) { // Inventory slot, trade slot, unit price, quantity. await trade(staff, "trade1", 100000, 1); } // Offer 10,000,000 gold for one +9 staff in trade2. await wishlist("trade2", "staff", 10000000, 9, 1); } open_example_shop().catch(show_json);
