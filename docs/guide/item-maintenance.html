PROTECT YOUR GEAR
Item Maintenance

Smith the Locksmith protects valuable items. Sir Bob the Scrollsmith can remove an applied stat from eligible equipment.

Manual

Visit Smith in Desertland. A lock blocks ordinary destructive item actions until you pay to unlock it. A seal is stronger: beginning its unlock starts a two-day wait, and you must return after the wait to finish.

Visit Sir Bob to remove an applied stat. The service shows the cost and returned stat scroll before you confirm. You need room for the returned scroll.

CODE

Each service accepts an inventory position. Run it while standing near the matching specialist.

async function maintain_items() { await lock_item(0); await seal_item(1); var result = await unlock_item(1); if (result.in_progress) { game_log(result.hours + " hours remain on the seal"); } // Sir Bob removes the applied stat from slot 2. var destat = await destat_item(2); game_log("Returned " + destat.quantity + " " + destat.scroll); }

References: lock_item, seal_item, unlock_item, destat_item.

De-statting removes only the applied stat. It does not remove the item's upgrade or compound level. Check the returned scroll and cost in the result.
