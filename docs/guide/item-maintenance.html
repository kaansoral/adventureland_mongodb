Item Maintenance

Smith protects valuable items from ordinary destructive actions. Sir Bob removes an applied stat while preserving the item's upgrade or compound level.

Lock, Seal, Unlock
LockBlocks selling, upgrading, compounding, dismantling, destroying, and other ordinary destructive item actions. Smith can remove it immediately for the shown price.
SealUses stronger protection. The first unlock visit begins an unsealing wait; return to Smith after the timer ends to finish.
UnsealingThe item remains protected while its marker shows that unsealing is in progress. Calling unlock again reports the remaining time.
Verify the slotEvery routine works on an inventory position. Re-read character.items[slot] immediately before changing it.

Stat Scrolls Returned

Sir Bob's preview names the scroll and quantity returned and shows the gold cost. De-statting removes only the applied stat: the item's +4 level in this example remains +4. Keep enough inventory space for the returned scroll stack.

Locking protects an item; it does not make risky attempts safe. Unlock only when you are ready to perform the intended action, then protect the item again.
CODE
async function protect_named_item(name) { var slot = locate_item(name); if (slot === -1) return game_log(name + " is not in inventory"); if (character.items[slot].l) return game_log(name + " is already protected"); await lock_item(slot); // Stand beside Smith. game_log(name + " is locked"); } protect_named_item("fireblade").catch(show_json);
async function check_sealed_item(slot) { var result = await unlock_item(slot); if (result.in_progress) { game_log(result.hours + " hours remain"); return; } game_log("The item is unlocked"); } async function remove_applied_stat(slot) { var item = character.items[slot]; if (!item || !item.stat_type) return game_log("That item has no applied stat"); var result = await destat_item(slot); // Stand beside Sir Bob. game_log("Returned " + result.quantity + " " + result.scroll); }
