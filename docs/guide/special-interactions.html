NOT EVERYTHING IS A SHOP
Strange Interactions

Terminals, levers, trees, statues, and jailers follow their own local rules. Approach until their interface appears, then read the exact action before using it.

New Year TreeWhen awake, it can grant holiday spirit and perhaps a token. Keep inventory space free.
MainframeCyberland's visible terminal accepts its own contained command set.
⇊Resort LeverWorks only beside the lever in its proper room and moves you through that interaction.
JailordThe LEAVE action exits the jail when its normal server checks allow it.
The Invisible Statue
Selected Eligible Item
→
POOFItem Destroyed

The statue in Spooky Town accepts an inventory item and offers POOF. This permanently destroys the selected item, though the statue has strange exceptions. Locked items are refused.

A visible character, guard, lottery host, wheel, or machine may currently offer only dialogue. If no action appears, there is no hidden service to click.
