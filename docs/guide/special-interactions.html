NOT EVERYTHING IS A SHOP
Special Interactions

Some places answer only when you stand beside them: terminals, levers, signs, statues, gates, and jailers. Their visible interface is part of the interaction.

Manual

Approach the object until its panel or prompt appears, then use the action it presents. Cyberland's Mainframe takes commands through its terminal. The Resort lever works only from its proper room. The Mainland PVP memorial opens the recent record. When the New Year tree is awake, it can bestow holiday spirit and perhaps a token; keep inventory space free.

The invisible statue in Spooky Town accepts an item and offers POOF. This destroys the item, though the statue has strange exceptions. Locked items are refused. Jailord's LEAVE action exits the jail.

If a guard, lottery host, wheel, or curious machine gives only a line of dialogue and no action, it is not currently offering a functional service. No secret click is required.

CODE

interact supports the New Year tree and Resort lever as well as monster hunts. leave exits supported special areas. destroy permanently consumes the chosen inventory item and receives the statue's special handling only when you are beside it.
