Run More Than One Character
Adventure Land supports browser windows, child character frames, COM, and Mainframe. Choose one method for each character. Do not load the same character twice.
Browser Windows
Open another game client from character selection with > New Game Window, or type /window in chat. Each window renders the complete game and runs that character's CODE.
Launch Through COM
Open COM, select Characters, and press Deploy to open an owned character in a new window. COM also shows where your characters are connected.
Mainframe
Mainframe runs each owned character in a contained, headless machine without keeping a browser open. Choose a CODE slot and live realm for each character. A new access window costs 1 Shell for 60 minutes; reconnecting during that window does not charge again. Mainframe refuses to start a character that is already active elsewhere.
Child Characters
Type /start CHARACTERNAME in chat, or use CODE, to run another owned character inside the current browser. Coordinate characters with trusted CODE messages:
start_character("CHARACTERNAME"); send_cm("CHARACTERNAME", {command: "follow"}); character.on("cm", function (message) { if (message.name !== "CHARACTERNAME") return; log(message.message); });
Observe and Coordinate
Use COM or /comm to observe connected characters. Use send_cm for character-to-character instructions, and always check the sender before acting on a message.
