GOLD IN, FORTUNE OUT
Tavern Games

The Tavern's dice table and slot machine are gold games of chance. Read the wager twice. The house has already read it once.

Manual

Dice: choose a number, choose Up or Down, enter the wager, then place the bet. Up wins on a roll at or above the chosen number; Down wins at or below it. The panel shows the payout, house edge, limits, and whether betting is open.

Slots: each play costs the amount shown by the machine and enters its short queue. Wait for the result before trying again. A machine that presents only dialogue or says its host is absent is not currently accepting a game.

CODE

Read the current house information first. A completed losing wager fulfills its Promise with won: false; an invalid wager or unavailable machine rejects.

async function tavern_example() { var house = await get_tavern_info(); game_log("House edge: " + house.edge + "%"); game_log("Maximum covered win: " + house.max); var dice = await bet_dice("down", 55, 10000); game_log(dice.won ? "Won " + dice.net : "Lost " + dice.wager); var slots = await play_slots(); game_log(slots.won ? "Slots paid " + slots.payout : "No luck"); }

References: get_tavern_info, bet_dice, play_slots.

Dice and slots spend gold immediately. Call get_tavern_info() first to read the current house edge and the largest win the tavern can cover.
