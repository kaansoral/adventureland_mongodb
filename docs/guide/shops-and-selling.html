Buying
1. Find the right merchantA merchant can sell only the items in that shop. The Computer lets CODE reach ordinary NPC stock from farther away.
2. Inspect one itemRead its price, currency, and stack behavior. Buying 100 means 100 units, not 100 stacks.
3. Keep free spaceA compatible stack can grow; otherwise the purchase needs an empty inventory position.
4. Choose currency when neededbuy() uses the available shop currency. Use the explicit gold or Shells routine when you must forbid the other.
Selling

Open a nearby merchant and right-click the inventory item you want to sell. Ordinary NPC resale is immediate. Locked items and items already involved in another action are refused.

CODE sales do not open a confirmation. Verify the item name, level, quantity, special property, stat, and lock marker from the current slot immediately before selling.
CODE
async function restock() { var hp_needed = Math.max(0, 1000 - quantity("hpot0")); var mp_needed = Math.max(0, 1000 - quantity("mpot0")); if (hp_needed) await buy_with_gold("hpot0", hp_needed); if (mp_needed) await buy_with_gold("mpot0", mp_needed); game_log("Potion stock is ready"); } restock().catch(function (error) { game_log(error.reason || error.message || "Restock failed"); });

Without a Computer, stand near a merchant who carries the item. With one equipped, ordinary NPC purchases can be made remotely.

async function sell_one_plain_item(slot, expected_name) { var item = character.items[slot]; if (!item || item.name !== expected_name) return; if (item.l || item.p || item.stat_type || item.level) { return game_log("Refusing to sell a modified item"); } await sell(slot, 1); } // Deliberately names both the slot and expected item. // sell_one_plain_item(0, "coat").catch(show_json);
