DAISY'S WORK
Monster Hunts

Daisy assigns a monster type and a number to defeat. Finish the hunt on the server where you accepted it, then return for monster tokens.

Manual

Visit Daisy on Mainland and ask for a hunt. The hunt appears among your conditions with its target, remaining count, server, and time. Defeat the named monsters before it expires, then speak to Daisy again to claim the reward.

Merchants cannot accept monster hunts. If you change server, your existing hunt does not become a hunt for the new server.

CODE

interact currently supports the complete monster-hunt interaction: the first call starts a hunt, and a later call at Daisy completes a finished one.

async function visit_daisy() { await smart_move("monsterhunter"); var result = await interact("monsterhunt"); if (result.started) game_log("A new hunt begins"); if (result.completed) game_log("Hunt reward claimed"); // Current hunt data, when one is active: show_json(character.s.monsterhunt); }

References: interact, smart_move.

Do not repeatedly call the interaction while fighting. Read character.s.monsterhunt, finish the assigned count, then return to Daisy.
