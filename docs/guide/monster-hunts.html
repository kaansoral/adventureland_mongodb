DAISY'S WORK
Monster Hunts

Daisy marks one monster type and a number to defeat. Finish on the server that issued the hunt, then return to her for a Monster Token.

Accept · Hunt · ReturnYour condition bar holds the target, remaining count, server, and time. The reward is not automatic: completed hunts must be turned in to Daisy.

Follow the Hunt Condition
Targetid is the monster key. Use G.monsters[id].name for its display name.
Remainingc counts down only for eligible kills of the assigned monster.
Serversn records the realm. Kills elsewhere do not advance this assignment.
Timems is the remaining duration. Return before the condition expires.

If the count reaches zero, stop hunting and return to Daisy. Merchants cannot accept hunts. A server change does not move an existing assignment to the new realm.

Do not repeatedly call Daisy while a hunt still has a remaining count. The server will refuse it; read character.s.monsterhunt instead.
CODE
function show_hunt() { var hunt = character.s.monsterhunt; if (!hunt) return game_log("No active monster hunt"); var name = G.monsters[hunt.id].name; game_log(name + ": " + hunt.c + " remaining on " + hunt.sn); } show_hunt();
async function visit_daisy() { await smart_move("monsterhunter"); var hunt = character.s.monsterhunt; // Start a hunt only when none exists; turn in only at zero. if (!hunt || hunt.c === 0) { var result = await interact("monsterhunt"); if (result.started) game_log("A new hunt begins"); if (result.completed) game_log("Monster Token received"); return; } game_log(hunt.c + " targets remain"); } visit_daisy().catch(show_json);
