Fishing & Mining

Gathering is a Merchant specialty. A level 16 Merchant can fish with a rod or mine with a pickaxe at the matching gathering zone.

Manual

Equip the tool in your main hand, stand at the edge of a fishing or mining zone, stop moving, and use the matching skill. Keep 120 MP and at least one inventory space free.

The action takes a few moments and may find nothing. A successful attempt can also wear out a tool whose properties say it can break. The skill panel shows the long reuse time.

CODE

use_skill waits for the final gathering result, not merely the start of the animation.

async function gather(kind) { if (character.moving) return; if (is_on_cooldown(kind)) return; var result = await use_skill(kind); if (result.found) game_log("Found something"); else game_log("Nothing this time"); } gather("fishing"); // or "mining"

References: use_skill, is_on_cooldown, equip.

A failed location, movement, equipment, class, level, or MP check rejects the Promise. A fulfilled result with found: false is a completed attempt that found nothing.
Materials often continue into Crafting and Dismantling.
