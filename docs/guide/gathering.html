Fishing & Mining

Gathering is a Merchant specialty. A level 16 Merchant can equip the matching tool, stand inside a gathering zone, and spend time searching its local drop table.

FishingEquip a rod in the main hand and stand at the edge of a fishing zone.
MiningEquip a pickaxe in the main hand and stand inside a mining zone.

Before Each Attempt
Merchant · Level 16Other classes and lower-level Merchants cannot start these gathering skills.
Correct main-hand toolA rod starts fishing; a pickaxe starts mining. Having the tool only in inventory is not enough.
120 MP and one spaceKeep enough mana and at least one empty inventory position for a possible find.
Stopped inside the zoneMovement or standing outside the matching zone prevents the attempt from starting.

The action takes a few moments. A valid attempt can finish with nothing. On a find, the reward comes from that zone's own drop table; different fishing or mining places can produce different things.

CODE
async function gather(kind) { if (character.ctype !== "merchant" || character.level < 16) return; if (character.moving || character.mp < 120 || character.esize < 1) return; if (is_on_cooldown(kind)) return; var required = kind === "fishing" ? "rod" : "pickaxe"; var equipped = character.slots.mainhand; if (!equipped || G.items[equipped.name].wtype !== required) { return game_log("Equip a " + required + " first"); } var result = await use_skill(kind); game_log(result.found ? "Found something" : "Nothing this time"); } gather("fishing").catch(show_json); // or "mining"

use_skill waits for the gathering animation and tells you whether the completed attempt found something. A rejected Promise means a prerequisite failed before completion.

References: use_skill, is_on_cooldown, equip.

Gathered materials often continue into Crafting and Dismantling.
