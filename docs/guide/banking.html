ACCOUNT STORAGE
The Bank

The bank holds gold and items for your whole account. Every character sees the same vault, but only one of your characters can be inside it at a time.

Gold and items use different tellersMr. Rich handles the account's shared gold. Gabrielle and the other item tellers each open one named 42-slot pack.
GMr. Rich
Deposit carried gold or withdraw shared gold. You cannot deposit more than you carry or withdraw more than the bank holds.
42One Teller, One Pack
Every item teller controls a 42-slot pack. The first two packs are open on every account.
3Three Floors
The Bank, Basement, and Underground hold different packs. A pack can only be used from its own floor.

Shared Bank Pack

Open an item teller, then drag an inventory item into a bank slot. Drag it back to retrieve it, or move items between slots to organise the pack. Stackable items join compatible stacks when possible.

Items cannot be equipped, sold, upgraded, or sent while stored. PVP markings are removed when an item is banked. Blocked items and operations already in progress are refused.

Leave at least one inventory space before retrieving an item. Automatic storage needs a compatible stack or an empty bank slot.
Opening More Space

Walk up to a closed teller to see its current price in gold or Shells. The quote shown there is the price for that exact pack. Once opened, the pack remains part of the account.

The Bank Key opens the Basement. The Underground has its own key. A Diamond Key opens the next unopened teller; using any key consumes it. Deeper floors remain inaccessible until their door has been unlocked.

Basement KeyUnlocks the door from the Bank to its Basement.

character.bank exists while you are inside the bank. It contains the shared gold and every open pack available to the character.

async function bank_trip() { await smart_move("bank"); // Gold is shared by every character on the account. await bank_deposit(100000); // No pack: prefer an existing stack, then the first free slot. var potions = locate_item("hpot0"); if (potions !== -1) await bank_store(potions); // Explicit pack and positions: // await bank_store(0, "items0", 5); // await bank_retrieve("items0", 5); // await bank_swap("items0", 5, 6); } bank_trip().catch(show_json);

Open a closed teller through CODE with open_bank_pack, for example await open_bank_pack("items2", "gold"). The character must be on the floor that owns that pack.
