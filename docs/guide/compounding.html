ITEM PROGRESSION
Compounding

Accessories and other compoundable items grow by combining three matching copies. All three must have the same item name and level.

Manual

Visit a compound shrine and place the three matching items into its three item slots. Add a compatible compound scroll and, if desired, an offering. Check the displayed chance and the exact items before beginning.

A failed compound can consume the items. Higher levels therefore require many copies, not merely one lucky accessory.

CODE

compound accepts four inventory positions, plus an optional offering position.

var copies = []; for (var i = 0; i < character.items.length; i++) { var item = character.items[i]; if (item && item.name === "ringsj" && (item.level || 0) === 0) copies.push(i); } var scroll = locate_item("cscroll0"); if (copies.length >= 3 && scroll !== -1) { compound(copies[0], copies[1], copies[2], scroll).then(function (result) { game_log(result.success ? "Compound complete" : "Compound failed"); }); }

Useful references: locate_item, item_grade, item_properties.

The example deliberately selects +0 copies. The server rejects mismatched copies, but your CODE should choose the intended level before sending the request.
