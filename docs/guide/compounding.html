ITEM PROGRESSION
Compounding

Accessories and other compoundable items grow by combining three matching copies. All three must have the same item name and level.

One Attempt

Visit a compound shrine. Place three matching items of the same level into its item slots, then add a compatible compound scroll. The shrine calculates the real chance for that exact set.

A success consumes three items and returns one item a level higher. A normal failure consumes all three. Locked items are refused.

1Match name and level
Three +1 rings can become one +2 ring. A +0 copy cannot join them.
2Match the scroll
Use a compound scroll that supports the items' current grade. A stronger scroll can improve the displayed chance.
3Count the copies
One guaranteed +N needs at least 3N base copies before failures: 3 for +1, 9 for +2, 27 for +3.
4Check every slot
The first selected item is the survivor on success. Verify properties, locks, and level before combining.
Offerings & Grace

An offering can improve the chance. Its grade matters, so compare the shrine percentage before committing it. Higher levels represent many consumed copies; plan the whole chain, not only the next roll.

Previous attempts can contribute grace. The shrine includes it in the shown chance, so check the preview before each roll.

A compoundable item becomes Exalted at the end of its defined path. At that point the server refuses another compound.
CODE

compound accepts four inventory positions, an optional offering position, and calculation mode. Previewing resolves with the exact chance without consuming or moving anything.

async function compound_three(name, level, minimum_chance) { var copies = []; for (var i = 0; i < character.items.length; i++) { var item = character.items[i]; if (item && item.name === name && (item.level || 0) === level) copies.push(i); } var scroll = locate_item("cscroll0"); if (copies.length < 3 || scroll === -1) return; var preview = await compound(copies[0], copies[1], copies[2], scroll, null, true); game_log("Chance: " + (preview.chance * 100).toFixed(2) + "%"); if (preview.chance < minimum_chance) return; var result = await compound(copies[0], copies[1], copies[2], scroll); game_log(result.success ? "Compound complete" : "Compound failed"); } compound_three("ringsj", 0, 0.9).catch(show_json);

Useful references: locate_item, item_grade, item_properties.

If compound() rejects, no compound started. If it returns success: false, the roll happened and all three accessories were lost.
