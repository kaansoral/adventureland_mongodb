ITEM PROGRESSION
Upgrading

Weapons, armor, and other upgradeable items grow one level at a time. Every normal attempt needs the item and a compatible upgrade scroll. An offering is optional.

Cue and the Upgrade Shrine
Use the item slot, upgrade-scroll slot, and optional offering slot. The displayed chance is for exactly what you placed.

→
An upgradeable +0 item and a compatible scroll attempt to make that item +1.
One Attempt

Visit an upgrade shrine and place the item and scroll into their marked slots. The shrine calculates the real chance for that exact item, scroll, offering, and character. Read it before pressing UPGRADE.

A successful attempt raises the item by one level. A failed normal upgrade destroys the item. A locked item is refused instead of risked.

1Read the grade
The item tooltip shows Normal, High, Rare, Legendary, or Exalted as it advances.
2Match the scroll
A scroll must support the item's current grade. A stronger scroll can improve the displayed chance.
3Preview again
Changing the item, scroll, or offering changes the calculation. Use the percentage shown on the shrine.
4Protect your plan
Keep a spare, lock the copy you will not risk, and wait for the result before moving another item.

Offerings, Grace & Stats

Primlings, Primordial Essences, stronger offerings, and certain metals can improve a chance. Their strength matters: do not spend one until you have compared the percentage with and without it.

Primling
An offering for upgrade and compound attempts.
Primordial Essence
A stronger offering; preview its exact effect first.

Upgrade and compound history can build grace. The shrine already includes grace in the shown chance, so check the preview each time.

Stat scrolls are different. They replace the selected stat on armor carrying a Stat attribute. Higher-grade armor consumes more copies of the stat scroll, and the shrine shows the required quantity.

Exalted means the item has reached the end of its defined upgrade path. Different item families reach grades at different levels.
CODE

Pass inventory positions to upgrade. Use calculation mode first; it resolves immediately with the exact chance and does not consume or move anything.

async function upgrade_item(item_name, scroll_name, minimum_chance) { var item = locate_item(item_name); var scroll = locate_item(scroll_name); if (item === -1 || scroll === -1) return; var preview = await upgrade(item, scroll, null, true); game_log("Chance: " + (preview.chance * 100).toFixed(2) + "%"); if (preview.chance < minimum_chance) return; var result = await upgrade(item, scroll); if (result.success) game_log(item_name + " is now +" + result.level); else game_log("The upgrade failed"); } upgrade_item("coat", "scroll0", 0.9).catch(show_json);

Useful references: locate_item, item_grade, item_properties, lock_item.

If upgrade() rejects, no upgrade started. If it returns success: false, the roll happened and the item was lost.
