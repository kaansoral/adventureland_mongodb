ITEM PROGRESSION
Upgrading

Weapons, armor, and other upgradeable items grow one level at a time. Every attempt needs the item and a compatible upgrade scroll. An offering is optional.

Manual

Visit an upgrade shrine, place the item and scroll in their slots, then inspect the displayed chance before you begin. Add an offering when you want its protection. The item tooltip tells you its grade; use a scroll that supports that grade.

An unsuccessful attempt can destroy the item. Lock treasured gear until you are ready, and never treat the preview as a promise.

CODE

Pass inventory positions to upgrade. Wait for the Promise before starting another item operation.

async function upgrade_item(item_name, scroll_name) { var item = locate_item(item_name); var scroll = locate_item(scroll_name); if (item === -1 || scroll === -1) return; var result = await upgrade(item, scroll); if (result.success) game_log(item_name + " is now +" + result.level); else game_log("The upgrade failed"); }

Useful references: locate_item, item_grade, item_properties, lock_item.

A rejected Promise means the attempt could not begin. A fulfilled result with success: false means the attempt happened and failed.
