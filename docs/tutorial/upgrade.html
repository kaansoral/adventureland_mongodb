MANUAL

Buy one Basic Upgrade Scroll. Take a cheap +0 weapon or armor piece to Cue, place both in the upgrade window, and inspect the chance before you commit.

The item's current grade decides which scroll it needs. The item and scroll are consumed on failure. Offerings and grace can help with difficult attempts; locking prevents an item from being upgraded at all.

OPTIONAL CODE

This selects a normal-grade upgradeable item. It will only attempt the upgrade after you deliberately change the confirmation line:

async function upgrade_once() { await smart_move(find_npc("newupgrade")); var item_num = character.items.findIndex(function (item) { return item && G.items[item.name].upgrade && item_grade(item) === 0; }); var scroll_num = locate_item("scroll0"); if (item_num === -1 || scroll_num === -1) throw {reason: "missing_item_or_scroll"}; var preview = await upgrade(item_num, scroll_num, null, true); game_log("Upgrade chance: " + (preview.chance * 100).toFixed(2) + "%"); var CONFIRM_UPGRADE = false; if (!CONFIRM_UPGRADE) throw {reason: "read_the_chance_then_confirm"}; await upgrade(item_num, scroll_num); } upgrade_once().catch(function (error) { show_json(error); });

Calculation mode consumes nothing. Read its chance, then change CONFIRM_UPGRADE to true only if you accept the risk.
