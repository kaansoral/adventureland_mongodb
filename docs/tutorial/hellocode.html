CODE is a companion, not a gate.

Everything you have done so far can stay manual. CODE becomes useful when you want your character to watch, repeat, coordinate, or react while your attention is elsewhere.

MANUAL

Keep playing exactly as you are. Leave CODE disengaged until you want it. No adventure should demand JavaScript at the door.

OPTIONAL CODE

Open CODE. The default script uses potions and loots chests. Change its first line to:

var attack_mode = true;

Press Engage!. The rest of the default script finds suitable monsters, moves into range, and attacks. Disengage before making a large change.

Most actions return a Promise. Handle success and failure when an action matters:

smart_move("goo").then(function () { game_log("Arrived."); }).catch(function (error) { show_json(error); });

Safety: Use public functions from the CODE Docs. Do not copy code you do not understand, especially code that sells, sends, destroys, upgrades, or trades items.
