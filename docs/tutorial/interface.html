MANUAL

Open INV. Right-click equipment to wear it and right-click an equipped slot to remove it. Drag items to keep the bag tidy.

HP and MP potions share a short cooldown. Use the one you need; carrying them is not the same as drinking them.

OPTIONAL CODE
var weapon = locate_item("blade"); if (weapon !== -1) equip(weapon); use_hp_or_mp();

Replace "blade" with an item key from your bag. use_hp_or_mp() only drinks when recovery is useful.
