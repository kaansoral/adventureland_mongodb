MANUAL

Open SKILLS. Read your class skills, their MP costs, ranges, and cooldowns. Put the ones you use on the skillbar.

Regeneration costs time; potions cost gold and share a cooldown. If you fall, respawn when the way is safe. Death takes experience, not your whole adventure.

OPTIONAL CODE
if (character.hp < character.max_hp && can_use("regen_hp")) { use_skill("regen_hp"); } if (character.rip) respawn();

For class skills, read G.skills, then pass the documented target when one is required.
