MANUAL

Left-click a Goo to target it. Move close, then right-click it to attack. When it falls, click the chest before it fades.

Watch your HP. Potions are brave little bottles, but they cannot help from the shop shelf.

OPTIONAL CODE

This finds one Goo, approaches it, attacks when ready, and checks for chests:

var target = get_nearest_monster({type: "goo"}); if (target) { change_target(target); if (!is_in_range(target)) move( character.x + (target.x - character.x) / 2, character.y + (target.y - character.y) / 2 ); else if (can_attack(target)) attack(target); } loot();

Run it again as the fight changes. Later, a loop can do that watching for you.
