MANUAL

Bring Cue three accessories with the same name and level, plus a compatible Compound Scroll. Place all four, inspect the chance, then decide.

A failure consumes all three accessories and the scroll. Every new level needs three of the previous level: a +2 already carries at least nine base copies inside it.

OPTIONAL CODE

With three +0 Rings of Joy and a Basic Compound Scroll in your bag:

async function compound_once() { await smart_move(find_npc("newupgrade")); var items = []; character.items.forEach(function (item, num) { if (item && item.name === "ringsj" && (item.level || 0) === 0) items.push(num); }); var scroll_num = locate_item("cscroll0"); if (items.length < 3 || scroll_num === -1) throw {reason: "missing_items_or_scroll"}; var preview = await compound(items[0], items[1], items[2], scroll_num, null, true); game_log("Compound chance: " + (preview.chance * 100).toFixed(2) + "%"); var CONFIRM_COMPOUND = false; if (!CONFIRM_COMPOUND) throw {reason: "read_the_chance_then_confirm"}; await compound(items[0], items[1], items[2], scroll_num); } compound_once().catch(function (error) { show_json(error); });

Calculation mode consumes nothing. Read its chance, then change CONFIRM_COMPOUND to true only if you accept the risk.
