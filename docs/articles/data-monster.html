Monster entities

Visible monsters live in parent.entities. Use get_monster(id), get_entity(id), or get_nearest_monster(filters) to obtain a current entity reference. G.monsters contains base monster definitions, not live HP, targets, conditions, or coordinates.

var target = get_nearest_monster({ type: "goo", no_target: true, path_check: true, }); if (target && target.visible && !target.dead) attack(target);

When an entity leaves view, an old object reference stops receiving updates and its visible value becomes false. Resolve a fresh entity before acting.

Identity and location

{ id: "376", type: "monster", mtype: "goo", // Key from G.monsters name: "Goo", skin: "goo", map: "main", in: "main", x: 200, y: 300, width: 23, height: 22, visible: true, dead: false, }

dead can also contain a reason such as map or vision when the entity is no longer actionable.

Vitals and combat

{ hp: 20000, max_hp: 50000, mp: 100, level: 8, xp: 1200, attack: 120, frequency: 0.4, speed: 36, range: 12, damage_type: "physical", armor: 0, resistance: 750, apiercing: 0, rpiercing: 0, evasion: 12.5, reflection: 5, dreturn: 3, lifesteal: 120, target: "CharacterName", }

Live monster stats can differ from G.monsters[mtype] because of level, map, server mode, conditions, and runtime scaling.

Movement and conditions

{ moving: true, vx: 36, vy: 0, from_x: 200, from_y: 300, going_x: 300, going_y: 300, s: { cursed: { ms: 400 }, }, }

s contains active monster conditions. Movement vectors and endpoints are meaningful while moving is true.

Optional monster traits

{ aggro: 0.5, rage: 0.5, respawn: 10, difficulty: 1.25, humanoid: false, cooperative: true, immune: true, "1hp": true, abilities: { portal: { cooldown: 0 }, }, spawns: [ [200, "nerfedmummy"], ], }

Traits are monster-specific and often absent. Inspect G.monsters[target.mtype] and the live entity instead of assuming every field exists.

Definitions and spawn packs

show_json(G.monsters.goo); show_json(G.maps.main.monsters);

G.maps[map].monsters describes spawn packs and boundaries. A definition or pack is not proof that a particular monster is currently alive or visible; use live entity helpers for action code.
