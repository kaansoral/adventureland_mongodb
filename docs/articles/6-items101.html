Items are defined in G.items. Each entry describes an item type. One example:

"fclaw":{ "type": "weapon", "wtype": "fist", "skin": "fclaw", "attack": 14, "range": 5, "ability": "freeze", "attr0": 0.2, "int": 8, "upgrade":{ "attack": 4, "range": 1.5, "attr0": 0.1, }, "name": "Frozen Claw", "g": 72000, "a": true, "grades": [0,7], }

Its type is weapon and its weapon type, wtype, is fist. Inspect G.classes to see which classes can use each weapon type. The visible name is Frozen Claw; its definition key is fclaw.

grades contains the upgrade levels where the item becomes high grade and rare grade. [0, 7] means high grade at +0 and rare grade at +7. Use item_grade instead of duplicating the grade calculation.

character.items is the live inventory array. An actual inventory entry refers back to its definition with name:

{ "name": "fclaw", "level": 8, }

Inventory slots can be null. Do not assume every array index contains an item. Common instance fields include level for upgraded/compounded items, q for stack quantity, p for a special property, l for a lock marker, and stat_type for an applied stat. Fields appear only when relevant.

for (var slot = 0; slot < character.items.length; slot++) { var item = character.items[slot]; if (!item) continue; var definition = G.items[item.name]; game_log(slot + ": " + definition.name + " +" + (item.level || 0)); }

G.items is definition data, not proof that your character owns an item. Conversely, an inventory item is instance data and does not repeat the complete definition. Read both when necessary.

Finding and counting

var scroll_slot = locate_item("scroll0"); var scroll_count = item_quantity("scroll0"); if (scroll_slot !== -1) { show_json(character.items[scroll_slot]); show_json(G.items[character.items[scroll_slot].name]); }

Use locate_item to find a matching slot and item_quantity to count stack quantities. Both accept optional filters for instance fields.

Changing items

Actions such as buy, sell, equip, upgrade, compound, craft, exchange, send_item, and bank functions return Promises. Await them and handle rejection; the server revalidates ownership, quantities, range, cost, compatibility, and action state.

async function equip_first(name) { var slot = locate_item(name); if (slot === -1) throw { failed: true, reason: "not_owned", name: name }; return await equip(slot); }

Inventory indexes can change after an action. Locate the item again before the next independent operation rather than keeping a slot number indefinitely.
