Coordinate system

Adventure Land maps use two-dimensional coordinates. Positive X moves right, negative X moves left, positive Y moves down, and negative Y moves up.

move(100, 0); // Right of the origin move(0, 100); // Below the origin move(-100, 0); // Left of the origin move(0, -100); // Above the origin

character.x and character.y are your current map coordinates. A coordinate is meaningful only with its map and instance:

var here = { map: character.map, in: character.in, x: character.x, y: character.y };

Two identical X/Y pairs on different maps or in different instances are not the same place. distance returns a very large value when compatible map or instance fields disagree.

Nearby entities also expose real_x and real_y internally. Public movement routines and ordinary CODE should use x/y unless a documented function specifically requires otherwise.
