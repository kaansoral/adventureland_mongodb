Mainframe

Mainframe keeps your characters running Adventure Land CODE when your browser is closed. Each character runs in its own small machine and uses one of your saved CODE slots.

Open Mainframe to choose a character, CODE slot, and live realm. Mainframe is also visible in COM and on /comm.

Cost

A new access window costs 1 Shell and lasts 60 minutes. The Shell is charged before the character starts. Disconnecting does not pause the window. Reconnecting the same character while its window is active costs nothing.

Mainframe refuses to load a character that is already active elsewhere. It never replaces a different running assignment. A character can have only one Mainframe assignment at a time.

What CODE can do

Mainframe supports the public CODE function directory without a browser DOM. Combat, movement, inventory, crafting, social, mail, trade, storage, and event methods use normal game actions. Buttons, drawings, focus, and other display-only calls become harmless headless operations.

smart_move uses Mainframe navigation instead of running the browser's exhaustive pathfinder. Your code keeps the same public call.

await smart_move("bank"); await smart_move({ map: "main", x: -100, y: -20 });

Containment

Every character runs with its own machine identity, read-only system image, fixed memory and CPU limits, bounded disk activity, syscall filtering, and no internet interface. Character actions can reach Adventure Land only through the Mainframe bridge. Runtime observations come back from the authenticated game server, so requested actions and confirmed movement are reported separately.

If CODE loops forever, allocates too much memory, or repeatedly writes, its machine remains bounded and can be stopped without taking another character with it.

Automation interfaces

Your own service can control Mainframe through the JSON API. AI clients can use the same operations through MCP. Both interfaces enforce the same account ownership, billing, assignment, and CODE-slot checks as the web page.

The Connect an AI panel on Mainframe creates, rotates, copies, and revokes the account token. The MCP teaches clients the game through native resources and prompts; see Adventure Land MCP for AI for setup, CODE guidance, and the source map it receives.

Use a unique request_id when linking a character. Reuse that ID only when retrying the same request. This makes a lost response safe to retry without charging twice.

{ "character": "YourCharacter", "request_id": "my-service:link:000001", "code_slot": "1", "server": "US I" }
