The account API

parent.api_call(method, args, options) sends a POST request to Adventure Land's account/backend API. This is different from real-time character actions such as attack, move, or send_item, which use the character's game-server socket.

async function inspect_account_data() { try { var result = await parent.api_call("pull_friends", {}, { timeout: 15000 }); show_json(result); } catch (error) { game_log("API failed: " + error.reason); } } inspect_account_data();

The returned Promise fulfills with the API result. Failed API results, network errors, and configured request timeouts reject with a structured error. Use try/catch or .catch.

The optional options.timeout is measured in milliseconds. API calls are not intended for combat loops or high-frequency polling.

Additional information events

Some API responses carry additional information records. Those records are also emitted through game.on("api_response", ...) after the main request settles:

game.on("api_response", function (data) { if (data.type == "merchants") show_json(data); }); parent.api_call("pull_merchants").catch(function (error) { game_log("Merchant lookup failed: " + error.reason); });

Prefer a documented public CODE routine when one exists. For example, use upload_code instead of calling save_code directly. Low-level API method names and payloads are advanced, compatibility-sensitive interfaces and can evolve independently of the public CODE function directory.
