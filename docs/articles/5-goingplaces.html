The simplest way to move your character is move.

move(100, -50); // Walk directly toward X: 100, Y: -50; returns a Promise

move sends one direct walking segment. It cannot route around obstacles or cross maps. Its Promise reports the movement request; use can_move_to first when the direct segment may be blocked.

smart_move calculates and follows a route. Its Promise fulfills when the destination is reached and rejects if the trip is interrupted, cannot be found, disconnects, or times out.

smart_move(100, -50); smart_move({ x: 100, y: -50 }); smart_move({ x: 100, y: -50, map: character.map }); // These forms describe the same destination. Run one at a time.

Named destinations can be map names, monster types, NPCs, items, quests, or other destinations understood by the smart-move resolver:

async function travel_to_bank() { try { await smart_move("bank"); game_log("Arrived at the bank"); } catch (error) { game_log("Travel failed: " + error.reason); } } travel_to_bank();

Starting a different smart route interrupts the previous route. Repeating the same active destination shares the existing trip. Use stop("move") to deliberately cancel walking.
