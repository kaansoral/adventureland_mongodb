NPC Objects

Adventure Land has two useful NPC data layers. G.npcs describes every NPC type, while a nearby NPC entity describes the copy currently visible on your map.

show_json(G.npcs.newupgrade); show_json(find_npc("newupgrade")); show_json(get_nearest_npc());

G.npcs is indexed by stable NPC IDs such as newupgrade, craftsman, and transporter. Display names can change; use the ID in CODE.

{ name: "Cue", role: "newupgrade", skin: "newupgrade", says: "+1" }

Common definition fields:

name — player-facing name.
role — the service or interaction family used by the game client.
skin — sprite or appearance key.
says — short overhead line, sometimes selected from an array.
interaction — longer dialogue shown when the NPC has no specialist panel.
items — item IDs sold by a merchant.
quest — collection or quest interaction key.
side_interaction — contextual dialogue displayed beside a specialist grid.

Map placement lives in G.maps[map].npcs. A placement contains an NPC id and either one position or a movement path in positions.

var cue = find_npc("newupgrade"); if (cue) await smart_move(cue);

find_npc(id) searches static map placements and returns smart-moveable coordinates. Seasonal or server-created NPCs may not be placed in the static map data.

A visible NPC entity is a PIXI-backed world object. Useful live fields include:

id — live entity ID.
npc — stable key into G.npcs.
type — normally "npc".
map — current map.
x and y — current coordinates.
var npc = get_nearest_npc(); if (npc) { game_log(npc.npc + " / " + npc.role); game_log("Distance: " + distance(character, npc)); }

get_nearest_npc() only searches NPCs currently rendered around the character. It returns the closest entity or null.

NPC services still enforce distance, inventory, currency, and item rules on the server. Travel close to the NPC, then call the documented routine for the service—such as upgrade, craft, or exchange_buy. Do not emit raw socket messages when a public routine exists.
