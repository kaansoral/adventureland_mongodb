Adventure Land MCP

The Adventure Land MCP server is the AI interface for the whole game. It exposes tools for research and account actions, resources that explain the game and CODE runtime, resource templates for exact records, and guided prompts for writing and operating character CODE. The JSON API remains the simpler interface for ordinary programs.

Get an account token

1. Sign in at https://adventure.land/. 2. Open https://adventure.land/mainframe. 3. Find “Connect an AI”. 4. Press “Create token”. If a token already exists, the button says “Rotate token”. 5. Confirm the warning. Rotation invalidates the previous token immediately. 6. Copy the connection details while they are visible. The plaintext token cannot be shown again. 7. Keep it out of character CODE, screenshots, public repositories, and chat messages.

Adventure Land stores only a hash of the token. One token can be active per account. Use the Revoke button on Mainframe if a token is exposed or no longer needed.

Connect an AI client

In the AI application's MCP or connector settings, add a remote server with these values:

Name: Adventure Land Transport: Streamable HTTP URL: https://adventure.land/mcp Header: Authorization: Bearer YOUR_TOKEN

Client configuration formats differ. If the client accepts a JSON server record, the equivalent shape is:

{ "mcpServers": { "adventure-land": { "url": "https://adventure.land/mcp", "headers": { "Authorization": "Bearer YOUR_TOKEN" } } } }

After connecting, ask the AI to read adventureland://guide/start-here. A conforming client also receives that instruction during MCP initialization.

Resource templates

adventureland://docs/{name} adventureland://code/functions/{name} adventureland://game-data/{section}/{name} adventureland://code/slots/{slot} adventureland://mainframe/characters/{character}

Find exact names with list_docs, list_code_methods, search_game_data, list_codes, and mainframe_get_dashboard. Resource URIs are validated and remain inside those public or account-owned collections.

How an AI should build a character

1. Read adventureland://guide/start-here. 2. Read mainframe_get_dashboard. 3. Inspect the character, live server choices, existing assignment, and available CODE slots. 4. Read an existing target slot before replacing it. 5. Find exact CODE methods with list_code_methods, then read each with get_code_method. 6. Find exact items, skills, monsters, maps, and recipes with search_game_data, then get_game_data. 7. Save the complete JavaScript slot with save_code. 8. Explain the charge if the character has no active Mainframe window. 9. Link with one stable request_id. 10. Verify connection, position, activity, deaths, performance, and CODE logs.

Combat loops belong inside contained character CODE. MCP is the control plane: it plans, deploys, observes, and corrects. It should not poll fast enough to become the combat loop.

Billing safety

mainframe_link_character can charge 1 Shell before a new 60-minute access window begins. If a response is lost, retry the same character, CODE slot, server, and request_id. Do not invent a new request ID for a network retry.

Reading state, logs, game data, documentation, CODE, resources, and prompts does not charge Shells. Disconnecting does not refund or pause active time.

Results and retries

Tool calls return JSON text in content and the same object in structuredContent. An application failure sets isError: true and includes a stable reason. HTTP 429 includes Retry-After; wait before retrying.

Read before mutating. Fetch a slot before replacing it, fetch the dashboard before linking or disconnecting, and use authenticated Mainframe observations as evidence. A request counter records an attempt, not a completed game action.

Rotate or revoke

Return to Mainframe's Connect an AI panel. Rotate token creates a new secret and invalidates the old one in the same transaction. Update the AI client's Authorization header. Revoke token disables MCP and JSON API access for that token without changing game login sessions or running characters.
