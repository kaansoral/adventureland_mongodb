Adventure Land MCP

The Adventure Land MCP server exposes the same game-data, documentation, CODE, and Mainframe operations as typed tools. Use it when an AI client needs live tool discovery and structured results. Use the JSON API for ordinary programs.

Connection

URL: https://adventure.land/mcp Transport: Streamable HTTP Authorization: Bearer YOUR_TOKEN

Create or rotate the token from a signed-in session:

var result = await parent.api_call("generate_token"); show_json(result);

The server is stateless. Send the token on every request. A token can only reach CODE slots and characters owned by its account.

Tool use

Start with get_api_info when the client needs the interface map. Use search_game_data before requesting a complete game-data section. Use list_docs and get_doc for game rules and guides, and list_code_methods for the character CODE surface.

Before starting a character, call mainframe_get_dashboard. It returns the account's characters, CODE slots, live server choices, Shell balance, paid access windows, and current assignments in one result.

Billing safety

mainframe_link_character can charge 1 Shell before a new 60-minute access window begins. Its input schema requires a unique request_id. If a response is lost, retry the same character, CODE slot, server, and request ID. Do not invent a new request ID for a network retry.

Reading state, logs, game data, documentation, and CODE does not charge Shells. Disconnecting does not refund or pause an active window.

MCP result shape

Tool calls return the same object twice: JSON text in content for broad client compatibility and the original object in structuredContent. Failed tool operations set isError: true and retain their structured reason.

{ "content": [{"type":"text","text":"{...}"}], "structuredContent": {"success":true,"servers":[...]}, "isError": false }

Request limits are returned by get_api_info. When the transport returns HTTP 429, wait for its Retry-After value before retrying. Full game-data sections have a smaller independent allowance; use search and exact-record reads for routine work.

Operating rules for AI clients

Read before mutating. Fetch the dashboard before linking or disconnecting. Fetch a CODE slot before replacing it. Explain a Shell charge before starting a new paid window. Never infer that an action succeeded from a request counter; use the authenticated runtime observation returned by Mainframe.

Character combat and movement are not direct MCP tools. Save CODE, link the owned character to Mainframe, then inspect its observed state and logs. This keeps arbitrary character logic inside its contained machine.
