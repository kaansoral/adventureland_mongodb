The character object

character is the public CODE object for your live character. It mirrors parent.character while normalizing coordinates to x and y. Read fields from character; use public functions such as move, equip, and use_skill to change server state.

show_json(character); show_json(character.slots); show_json(character.items); show_json(character.s);

Character updates are live but asynchronous. A Promise result and the next character update can arrive separately; function docs say when a call waits for both. Optional fields are absent when they do not apply.

Identity and location

{ name: "CharacterName", id: "CharacterName", type: "character", ctype: "warrior", // A key from G.classes owner: "OwnerID", // Empty for private characters you do not own level: 72, map: "main", in: "main", // Unique instance ID inside instances x: 12.5, y: 40, visible: true, me: 1, skin: "mwarrior", cx: ["santahat"], }

character.x and character.y proxy the underlying real_x/real_y. Nearby entities use ordinary x/y coordinates. map is the map key; in identifies the current instance.

Vitals, offense, and defense

{ hp: 2000, max_hp: 2500, mp: 360, max_mp: 960, xp: 978000, attack: 720, frequency: 1.2, // Attacks per second speed: 95, range: 40, armor: 420, resistance: 260, apiercing: 0, rpiercing: 0, evasion: 2.5, reflection: 0, crit: 0, lifesteal: 10, manasteal: 0.25, dreturn: 0, mp_cost: 24, }

Percentage-like fields are expressed in percentage points unless a specific definition says otherwise. The server has the final value; local values can be one network update behind a just-completed action.

Attributes and combat pressure

{ str: 206, int: 46, dex: 46, vit: 57, for: 10, courage: 2, mcourage: 2, pcourage: 2, fear: 0, targets: 2, }

Inventory, equipment, and currency

{ gold: 1200000000, cash: 200, // Shells isize: 42, esize: 40, items: [ { name: "gloves", level: 0 }, null, { name: "hpot0", q: 999 }, ], slots: { mainhand: { name: "blade", level: 9 }, offhand: null, "helmet": null, chest: { name: "coat", level: 8, stat_type: "str" }, pants: null, shoes: null, gloves: null, cape: null, belt: { name: "hpbelt", level: 4 }, ring1: null, ring2: null, earring1: null, earring2: null, amulet: null, orb: null, elixir: { name: "eggnog", expires: "2053-02-19T07:00:59.459Z" }, }, }

Inventory indexes run from 0 to character.isize - 1. Empty positions are null. Stack quantity is q; a missing q means one. Equipment slot availability can vary by class and item.

Conditions and ongoing actions

{ s: { cursed: { ms: 400 }, mluck: { ms: 120000, f: "MerchantName" }, }, c: { town: { ms: 3000 }, revival: { ms: 8000, f: "PriestName" }, }, q: { upgrade: { ms: 2000, len: 2000, num: 5 }, compound: { ms: 8000, len: 10000, num: 0 }, exchange: { ms: 3000, name: "gem0", num: 12 }, }, }

s contains active conditions, buffs, and debuffs. c contains cancellable channeling actions. q contains progressed item actions. Entries disappear when complete; test for their presence rather than retaining old references.

Movement

{ moving: true, vx: 95, vy: 0, from_x: 12.5, from_y: 40, going_x: 525.5, going_y: 40, }

Movement fields are meaningful while moving is true. Use is_moving, can_move_to, move, or smart_move rather than assigning them.

Social and runtime state

{ party: "LeaderName", guild: "XYZ", friends: ["OwnerID1", "OwnerID2"], stand: false, rip: false, afk: false, code: true, ping: 64.5, cc: 12.5, target: "MonsterID", focus: "CharacterName", }

friends contains owner IDs. target is usually a monster ID or character name. Use get_target and get_target_of to resolve visible entity objects.

Event methods

character.on(event, callback); character.once(event, callback); character.all(callback); character.remove(listener_id);
