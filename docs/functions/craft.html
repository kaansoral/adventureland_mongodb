craft(i0, i1, i2, i3, i4, i5, i6, i7, i8)

Crafts using up to nine inventory positions arranged as the crafting grid from top-left to bottom-right.

Returns: Promise resolving with the craft response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

craft(null, 0, null, null, 1, null, null, 2, null);
