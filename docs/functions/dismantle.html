dismantle(item_num)

Dismantles the item in an inventory slot using the normal dismantle rules.

Returns: Promise resolving with the completed dismantle response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

dismantle(0);
