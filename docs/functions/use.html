use(name,target)

Backward-compatible multi-purpose helper: a numeric argument equips that inventory slot; a string argument uses that skill.

Returns: The Promise returned by equip or use_skill.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Prefer the explicit equip and use_skill functions in new code. Existing use calls remain supported.

Example:

use("attack", target); use(0);
