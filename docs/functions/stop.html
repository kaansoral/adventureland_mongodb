stop(action, second)

Stops movement or cancels a supported ongoing action.

Returns: Promise resolving when the stop is accepted, or rejecting for an invalid action or server failure.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Actions are move, smart, invis, teleport/town, and revival. stop("move") also interrupts smart_move and sends a zero-distance move; stop("smart") only stops the smart route.

Example:

async function example() { await stop("town"); await stop("smart"); } example();
