doneify(fn,s_event,f_event)

Legacy experiment that wraps an event-based function with a .done(callback) interface.

Returns: A wrapper function whose call returns an object containing done(callback).

Notes: Deprecated. Modern action functions return native Promises; use then, catch, or await. Kept only for backward compatibility.

Example:

var old_buy = doneify(buy, "buy_success", "buy_fail");
