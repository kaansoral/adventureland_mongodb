doneify(fn,s_event,f_event)

Adds the legacy .done(callback) interface to a Promise-returning or event-based function.

Returns: A wrapper whose calls return a native Promise with done(callback). The callback receives success as its first argument and the result or failure as its second.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: For modern functions, settlement follows the returned Promise. The optional event names preserve the old rxd-correlated fallback for legacy functions that do not return a Promise. Listeners are registered before invocation and removed after settlement.

Example:

var old_buy = doneify(buy, "buy_success", "buy_fail"); old_buy("hpot0").done(function (success, data) { game_log(success ? "Bought" : data.reason); });
