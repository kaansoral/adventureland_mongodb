send_party_invite(name, is_request)

Invites a character to your party, or sends a join request when is_request is truthy.

Returns: Promise resolving with the party acknowledgement, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

send_party_invite("Priest");
