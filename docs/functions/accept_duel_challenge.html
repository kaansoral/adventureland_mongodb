accept_duel_challenge(name, timeout_ms)

Accepts a live duel challenge from the named character.

Returns: Promise resolving after the duel instance is created and both leaders are assigned. The result includes action:"accepted", id, challenger, and vs. It rejects if the challenge expired, either leader is already dueling, either leader is in PVP, or the timeout expires.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Pass a character name or character object. Party members receive the normal duel invitation after the leaders enter. timeout_ms defaults to 10,000ms.

Example:

async function example() { var duel = await accept_duel_challenge("ChallengerName"); game_log("Duel: " + duel.id); } example();
