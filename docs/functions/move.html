move(x, y)

Requests a direct walk to map coordinates.

Returns: Promise resolving when the move request is accepted, or rejecting when walking is unavailable or the server refuses it.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: For collision-aware multi-map travel use smart_move. The Promise does not mean the character has already arrived.

Example:

move(character.x + 100, character.y);
