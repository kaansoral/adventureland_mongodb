auto_craft(name)

Finds the single-slot recipe ingredients in your inventory and crafts the named item.

Returns: Promise resolving with the craft response, or rejecting before the request when the recipe, ingredients, space, or gold are insufficient.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Ingredient quantities must exist in one inventory stack because that is the server crafting protocol.

Example:

auto_craft("computer");
