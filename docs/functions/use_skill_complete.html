use_skill_complete(name, target, extra_arg, timeout_ms)

Uses a skill and, for pickpocket, fishing, or mining, waits for the correlated terminal result instead of stopping at the initial in-progress acknowledgement.

Returns: Promise resolving with the final success or no-resource result. It rejects on pick/fishing/mining failure, an initial server failure, disconnect, or timeout. Other skills behave exactly like use_skill.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The timeout defaults to 20,000ms. Existing use_skill behavior is unchanged. Final results include response, place, request_id, and success; fishing/mining also include found. mode_resolve_all() turns completion failures into fulfilled failure objects.

Example:

async function example() { var result = await use_skill_complete("fishing", null, null, 20000); if (result.found === false) game_log("Nothing caught this time"); } example();
