get_lost_and_found(timeout_ms)

Retrieves the Lost and Found's current unlooted-chest listings.

Returns: Promise resolving with {success:true, items:[...]}. It rejects until the character has made a qualifying reserve donation, when too far away, or on timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Items are ordered as shown in the in-game shop and include the rid needed by buy_lost_and_found. timeout_ms defaults to 10,000ms.

Example:

async function example() { var listings = await get_lost_and_found(); show_json(listings.items); } example();
