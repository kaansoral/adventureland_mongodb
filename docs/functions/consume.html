consume(num)

Consumes or uses the item in the selected inventory slot.

Returns: Promise resolving with the equip/consume response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

consume(locate_item("elixirluck"));
