buy_with_shells(name, quantity)

Starts an item purchase using shells.

Returns: Promise for the initial server response. A successful start may resolve with {success:false, in_progress:true}; later account updates complete the purchase.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

buy_with_shells("computer", 1);
