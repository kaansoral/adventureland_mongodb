donate_gold(gold, timeout_ms)

Donates gold to the Lost and Found reserve.

Returns: Promise resolving with the donated amount, current merchant xprate, and reserve reply. Invalid amount, insufficient gold, distance, bank, and timeout failures reject.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Donations of at least 1,000,000 gold unlock Lost and Found listings for that character. Merchants receive reserve-rate XP. timeout_ms defaults to 10,000ms.

Example:

async function example() { await donate_gold(1000000); } example();
