async transport(map, spawn)

Uses a map transport and waits for the destination map to load when the server reports an in-progress transition.

Returns: Promise resolving with {success:true} after arrival or the immediate transport result, or rejecting on failure, disconnection, or the 20-second arrival timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Only one different transport may be active at a time. Repeating the same active destination shares the existing trip.

Example:

await transport("main", 0);
