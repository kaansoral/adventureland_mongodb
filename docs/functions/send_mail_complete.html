send_mail_complete(to, subject, message, item, timeout_ms)

Sends in-game mail and waits for the database-backed mail operation to finish.

Returns: Promise resolving with the correlated mail_sent response. It rejects on the correlated mail_failed response, an initial server failure, disconnect, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The item argument is a boolean flag; when truthy, inventory slot 0 is attached. The timeout defaults to 15,000ms. Use send_mail only when existing code intentionally needs the initial acknowledgement.

Example:

async function example() { await send_mail_complete("Merchant", "Supplies", "For the next run", false, 15000); } example();
