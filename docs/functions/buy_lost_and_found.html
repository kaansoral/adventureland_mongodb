buy_lost_and_found(rid, timeout_ms)

Buys one current Lost and Found listing by its revision ID.

Returns: Promise resolving after the item and gold changes are committed, with the purchased item and cost. It rejects without a qualifying donation, or when the listing, inventory, gold, health, distance, or timeout checks fail.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Pass either a rid string or a listing object returned by get_lost_and_found. timeout_ms defaults to 10,000ms.

Example:

async function example() { var listings = await get_lost_and_found(); if (listings.items.length) await buy_lost_and_found(listings.items[0]); } example();
