exchange_buy(token, name)

Buys an exchange reward directly with the named token item.

Returns: Promise resolving with the exchange purchase response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

exchange_buy("funtoken", "confetti");
