take_mail_item(mail_id, timeout_ms)

Takes an attachment from an in-game mail and waits until the item is in the live inventory.

Returns: Promise resolving with the correlated mail_item_taken response. It rejects when the mail is missing, already claimed, owned by another account, cannot fit in inventory, the server fails, the socket disconnects, or the timeout expires.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The timeout defaults to 15,000ms. A full inventory can still accept a stackable attachment when an existing stack has room. Failed or disconnected claims are released so the attachment remains available.

Example:

async function example() { await take_mail_item("ML_your_mail_id"); } example();
