send_friend_request(name)

Sends a friend request to a character name or character object.

Returns: Promise resolving with the server acknowledgement, or rejecting for no_target or another structured failure.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

send_friend_request("Wizard");
