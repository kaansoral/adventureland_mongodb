equip_cx(slot, cx_name)

Equips an owned cosmetic in a cosmetic slot.

Returns: Promise resolving with the cosmetic response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

equip_cx("head", "makeup105");
