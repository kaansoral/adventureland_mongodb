get_tavern_info(timeout_ms)

Retrieves the tavern's current house edge and largest win it can cover, without opening the tavern panel.

Returns: Promise resolving with edge as a percentage and max as gold. It rejects on timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Multiple calls can run at the same time; each one waits for its own reply. timeout_ms defaults to 10,000ms.

Example:

async function example() { show_json(await get_tavern_info()); } example();
