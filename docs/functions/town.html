async town()

Starts the town teleport and waits until the channel has ended.

Returns: Promise resolving with {success:true} after completion, or rejecting on server failure, interruption, disconnection, or the 10-second completion timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

async function example() { await town(); } example();
