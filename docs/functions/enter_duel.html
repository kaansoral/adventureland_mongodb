enter_duel(id, timeout_ms)

Enters a pending party duel by its duel ID.

Returns: Promise resolving after transport and team assignment, with action:"entered", id, and team. It rejects if the duel expired or started, the character is already dueling or in PVP, the character is not on either team, or the timeout expires.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: timeout_ms defaults to 10,000ms.

Example:

async function example() { await enter_duel(duel_id); } example();
