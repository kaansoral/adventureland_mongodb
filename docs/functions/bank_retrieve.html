bank_retrieve(pack, pack_num, num)

Moves an item from a bank pack into the inventory.

Returns: Promise resolving with the bank response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The inventory slot is optional; omit it to use the first suitable slot.

Example:

bank_retrieve("items0", 0, 12);
