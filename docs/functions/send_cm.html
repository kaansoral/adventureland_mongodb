async send_cm(to, message)

Sends a JSON-serializable CODE message to one character name or an array of names, using fast local delivery when possible and the server otherwise.

Returns: Promise resolving with {receivers, locals}. On partial failure the rejection also includes locally delivered names so callers do not resend them accidentally.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Listen with character.on("cm", function (data) { data.name; data.message; }). Server-routed messages consume communication capacity.

Example:

send_cm(["Warrior", "Priest"], { command: "farm", monster: "goo" });
