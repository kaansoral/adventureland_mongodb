bless_server(timeout_ms)

Spends 1,200 shells to bless the current server for three days and waits for the account transaction and live server state to complete.

Returns: Promise resolving with the correlated blessed response. It rejects on insufficient shells, another blessing request already in progress, server failure, disconnect, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The timeout defaults to 15,000ms. Success includes cost, blessed_by, and the initial remaining minutes. A disconnect can make the final outcome unknown if the server transaction has already committed.

Example:

async function example() { await bless_server(); } example();
