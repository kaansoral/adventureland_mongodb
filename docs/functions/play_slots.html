play_slots(timeout_ms)

Spends 1,000,000 gold at the tavern slots machine and waits for the spin result.

Returns: Promise resolving after the three-second spin with won, cost, payout, and net. A losing spin resolves with won:false. Validation and timeout failures reject.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: A second CODE-triggered spin is rejected while the first is active. timeout_ms defaults to 10,000ms.

Example:

async function example() { var spin = await play_slots(); game_log(spin.won ? "Jackpot!" : "No luck."); } example();
