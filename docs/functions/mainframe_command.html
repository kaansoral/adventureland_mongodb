mainframe_command(command, timeout_ms)

Runs one command through the in-world Cyberland Mainframe terminal.

Returns: Promise resolving with command, reply, and authorized after the Cyberland terminal answers. It rejects when the character is not beside the terminal, the input is invalid, the server refuses the action, or the timeout expires.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: This controls the in-world terminal, not the account Mainframe hosting service. Unknown commands resolve with the terminal's unauthorized reply and authorized:false. timeout_ms defaults to 10,000ms.

Example:

async function example() { var response = await mainframe_command("hello"); game_log(response.reply); } example();
