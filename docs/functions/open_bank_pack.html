open_bank_pack(pack, currency, timeout_ms)

Opens a bank pack using gold or shells and waits for the selected payment path to complete.

Returns: Promise resolving after the pack is available in the live bank state. It rejects for invalid input, server failure, insufficient funds, disconnect, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The character must be inside the bank map that owns the pack. Shell purchases default to a 15,000ms timeout and resolve only after both the shell charge and the new pack are saved.

Example:

async function example() { await open_bank_pack("items2", "shells"); } example();
