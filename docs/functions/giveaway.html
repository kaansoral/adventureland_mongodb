giveaway(slot, num, q, minutes)

Creates a timed merchant-stand giveaway from an inventory slot.

Returns: Promise resolving with the giveaway response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

giveaway("trade1", 0, 12, 20);
