async exchange(item_num)

Starts an item exchange and waits until the timed exchange completes and the reward slot is updated.

Returns: Promise resolving with {success:true, reward, num}, or rejecting on validation failure, disconnection, or the 30-second completion timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

exchange(0).then(function (data) { game_log("Received: " + data.reward); });
