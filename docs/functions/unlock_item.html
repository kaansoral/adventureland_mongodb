unlock_item(num)

Unlocks an inventory item, or reports the remaining seal time for a sealed item.

Returns: Promise resolving with the unlock response. A sealed item may resolve with {success:false, in_progress:true, hours}; other failures reject.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

unlock_item(0);
