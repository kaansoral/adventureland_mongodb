send_gold(receiver, gold)

Sends gold to a nearby character name or character object.

Returns: Promise resolving with the send response, or rejecting for no_target, range, amount, or another server failure.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

send_gold("Merchant", 100000);
