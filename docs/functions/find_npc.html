find_npc(npc_id)

Finds map coordinates for an NPC key from G.npcs, including seasonal NPCs while their event is active.

Returns: Object containing map, in, x, and y, or null when no location is found.

Example:

var potion_vendor = find_npc("fancypots");

During the anniversary, find_npc("anniversary_baker") locates Mira. You can also use smart_move("anniversary_baker").
