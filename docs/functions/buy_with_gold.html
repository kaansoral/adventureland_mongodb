buy_with_gold(name, quantity)

Buys an NPC item using gold. This is the explicit-gold form of buy.

Returns: Promise resolving with the purchased item and inventory position, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

buy_with_gold("hpot0", 100);
