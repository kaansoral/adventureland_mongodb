use_hp_or_mp()

Chooses HP or MP restoration from current ratios, respects the shared potion cooldown and safety window, and uses the selected potion skill.

Returns: Promise resolving with the skill response or with {success:false, used:false, reason} when no potion should be used.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

use_hp_or_mp();
