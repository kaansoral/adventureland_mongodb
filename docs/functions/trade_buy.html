trade_buy(target, trade_slot, quantity)

Buys from a visible player's current merchant listing, including its listing ID to prevent listing-swap fraud.

Returns: Promise resolving with the trade response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

var merchant = get_player("Merchant"); trade_buy(merchant, "trade1", 1);
