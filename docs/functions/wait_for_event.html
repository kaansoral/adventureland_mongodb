wait_for_event(emitter, event, timeout_ms, filter)

Waits for the next matching event from character, game, or another emitter that supports on plus remove/off.

Returns: Promise resolving with the event data. It rejects with invalid_emitter, invalid_event, invalid_filter, listener_error, filter_error, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The optional filter may return a value or a Promise. Non-matching events keep the listener active. The listener and timer are removed on every settlement path, and mode_resolve_all() converts failures into fulfilled failure objects.

Example:

async function example() { var loot = await wait_for_event(character, "loot", 5000, function (data) { return data.gold > 0; }); } example();
