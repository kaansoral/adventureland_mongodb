loot(id_or_arg)

Loots a specific visible chest or up to two eligible nearby chests.

Returns: Promise for the last chest request, or a resolved result explaining that safety blocked the call or nothing was available.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: loot(id) selects one chest. loot(true) routes through the commander context for legacy CODE-mode behavior.

Example:

loot(); // Loot nearby eligible chests
