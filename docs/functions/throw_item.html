throw_item(num, x, y)

Throws a throwable inventory item onto map coordinates.

Returns: Promise resolving with the throw response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

throw_item(0, character.x + 20, character.y);
