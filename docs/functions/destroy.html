destroy(num)

Permanently destroys the item in an inventory slot through the normal confirmation-free CODE path.

Returns: Promise resolving with the destroy response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: This action is destructive. Check the slot immediately before calling it.

Example:

destroy(0);
