accept_magiport(name)

Accepts a pending magiport invitation from the named mage.

Returns: Promise resolving with the server response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

accept_magiport("Wizard");
