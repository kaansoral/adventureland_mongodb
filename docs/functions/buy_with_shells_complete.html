buy_with_shells_complete(name, quantity, timeout_ms)

Buys an item with shells and waits for the account transaction and inventory update to complete.

Returns: Promise resolving with the correlated shell_purchase_complete response. It rejects on final purchase failure, an initial server failure, disconnect, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The timeout defaults to 15,000ms. Use buy_with_shells only when existing code intentionally needs the initial acknowledgement.

Example:

async function example() { await buy_with_shells_complete("computer", 1, 15000); } example();
