smart_move(destination, on_done)

Finds and follows a collision-aware route to coordinates, maps, monsters, NPCs, events, and named service destinations.

Returns: Promise resolving with {success:true} only after arrival, or rejecting with a structured reason such as invalid, interrupted, event_not_live, disconnected, or transport failure.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Legacy on_done callbacks remain supported. With return:true the callback reports outbound arrival, while the Promise waits for the complete round trip. Starting a different route interrupts the previous route; an identical active destination shares it.

Example:

await smart_move({ to: "goo", return: true });
