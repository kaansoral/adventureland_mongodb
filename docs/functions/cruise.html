cruise(speed)

Sets a server-enforced upper speed cap for the character.

Returns: Promise resolving with the cruise response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Use cruise(500) to restore a cap above ordinary movement speeds.

Example:

cruise(40);
