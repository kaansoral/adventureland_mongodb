get_secondhands(timeout_ms)

Retrieves Ponty's current recovered-item listings.

Returns: Promise resolving with {success:true, items:[...]}. It rejects on distance or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Items are ordered as shown in the in-game shop and include the rid needed by buy_secondhand. timeout_ms defaults to 10,000ms.

Example:

async function example() { var listings = await get_secondhands(); show_json(listings.items); } example();
