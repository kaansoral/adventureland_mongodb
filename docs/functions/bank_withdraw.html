bank_withdraw(gold)

Withdraws gold from the current bank account.

Returns: Promise resolving with the bank response, or rejecting when the character is not in a bank or the server refuses the action.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

bank_withdraw(100000);
