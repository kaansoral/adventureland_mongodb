get_pvp_history(timeout_ms)

Retrieves the server's recent PVP defeats without opening the history board.

Returns: Promise resolving with {success:true, list:[...]}. It rejects on timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The server returns up to 200 recent entries. Simultaneous calls are matched to their own replies. timeout_ms defaults to 10,000ms.

Example:

async function example() { var history = await get_pvp_history(); show_json(history.list); } example();
