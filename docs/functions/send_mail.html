send_mail(to, subject, message, item)

Starts sending in-game mail, optionally attaching the item in inventory slot 0.

Returns: Promise for the initial server response. A valid request resolves with {success:false, in_progress:true}; mail_sent or mail_failed arrives later.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The item argument is a boolean flag; when truthy, slot 0 is attached. The returned Promise does not wait for database-backed mail completion.

Example:

send_mail("Merchant", "Supplies", "For the next run", true);
