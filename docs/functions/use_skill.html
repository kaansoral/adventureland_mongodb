use_skill(name, target, extra_arg, timeout_ms)

Uses a named skill with an optional target and skill-specific extra argument.

Returns: One Promise for the completed skill call. Pickpocket, fishing, and mining wait for their correlated terminal result; other skills resolve with the ordinary server response.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Targets may be entity objects, character names, monster IDs, coordinate arrays for blink, or arrays for multi-target skills. If target is omitted, get_target() is used. Multi-target skills return one aggregate Promise, not an array. The optional timed-action timeout defaults to 20,000ms. Final timed-action results include response, place, request_id, and success; fishing/mining also include found.

Example:

async function example() { var result = await use_skill("fishing", null, null, 20000); if (result.found === false) game_log("Nothing caught this time"); } example();
