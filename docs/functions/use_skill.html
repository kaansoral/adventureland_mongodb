use_skill(name, target, extra_arg)

Uses a named skill with an optional target and skill-specific extra argument.

Returns: One Promise for the complete skill call, resolving with the aggregate server response or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Targets may be entity objects, character names, monster IDs, coordinate arrays for blink, or arrays for multi-target skills. If target is omitted, get_target() is used. Multi-target skills return one aggregate Promise, not an array of Promises.

Example:

use_skill("energize", get_player("Warrior"), 100); use_skill("3shot", [target1, target2, target3]); use_skill("blink", [100, -50]);
