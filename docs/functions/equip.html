equip(num, slot)

Equips the item in an inventory slot, optionally into a specific equipment slot.

Returns: Promise resolving with the equip response, or rejecting for invalid input or a server failure.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

equip(0, "mainhand");
