interact(name, timeout_ms)

Starts a supported named server interaction.

Returns: Promise. "monsterhunt" resolves when the hunt starts or is turned in, "newyear_tree" resolves after the spirit and possible token are applied, and "the_lever" resolves after arrival in the resort. Invalid interactions and failed server checks reject.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The tree and lever still use the server's normal location rules. Their timeout defaults to 5,000ms.

Example:

async function example() { await interact("monsterhunt"); await interact("newyear_tree"); await interact("the_lever"); } example();
