trade(num, trade_slot, price, quantity)

Lists an inventory item in one of your merchant trade slots.

Returns: Promise resolving with the listing response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Numeric slot 4 and string slot "trade4" are equivalent.

Example:

trade(0, 4, 100000, 1);
