mode_resolve_all()

Changes CODE Promise failures into fulfilled values for backward-compatible resolve-only control flow.

Returns: Nothing.

Notes: Call once near startup. Successful results have success:true where applicable; failures fulfill with failed:true and reason instead of running catch.

Example:

mode_resolve_all(); attack(target).then(function (data) { if (data.failed) game_log(data.reason); });
