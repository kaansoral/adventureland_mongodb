heal(target)

Performs the priest's normal heal against a visible character target.

Returns: Promise resolving with the heal/projectile response, or rejecting with a structured failure object such as not_found, too_far, cooldown, no_mp, or disabled.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

heal(character).then(function (data) { game_log("Heal sent"); });
