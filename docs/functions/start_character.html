start_character(name, code_slot_or_name)

Starts another character from your account in CODE-only mode, optionally with a code slot or file name.

Returns: Promise resolving when the character is running, or immediately when it already has a local runner. Rejects when the name or slot is invalid, the character is already active elsewhere, startup is interrupted, or the timeout expires.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Repeated calls for the same local character share its startup or reuse its active runner instead of creating duplicates.

Example:

async function example() { await start_character("Merchant", "merchant_code"); } example();
