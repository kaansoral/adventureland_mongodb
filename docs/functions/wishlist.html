wishlist(trade_slot, name, price, level, quantity)

Creates a buy listing in one of your merchant trade slots for an item key, price, level, and quantity.

Returns: Promise resolving with the wishlist response, or rejecting with a structured failure object.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

wishlist(1, "staff", 10000000, 9, 1);
