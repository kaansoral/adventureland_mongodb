unfriend(name, timeout_ms)

Removes a friend by character name or owner ID and waits for both account records to be updated.

Returns: Promise resolving with the correlated unfriend_complete response. It rejects on final unfriend failure, an initial server failure, disconnect, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The optional timeout defaults to 15,000ms. The Promise waits past the server's initial in-progress acknowledgement.

Example:

async function example() { await unfriend("CharacterName", 15000); } example();
