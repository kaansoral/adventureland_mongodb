unfriend(name)

Starts removing a friend by character name or owner ID.

Returns: Promise for the initial friend-system response. Database-backed completion and any later unfriend_failed response occur after this acknowledgement.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

unfriend("CharacterName");
