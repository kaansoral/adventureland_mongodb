destat_item(num, timeout_ms)

Removes the applied stat from an inventory item at the Scrollsmith and returns the appropriate stat scrolls.

Returns: Promise resolving after the item, gold, and returned scrolls are committed. The result includes num, cost, scroll, and quantity. Validation, distance, and timeout failures reject.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: This operation removes the applied stat but not the item's level. timeout_ms defaults to 10,000ms.

Example:

async function example() { await destat_item(0); } example();
