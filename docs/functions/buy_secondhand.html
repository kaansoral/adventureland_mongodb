buy_secondhand(rid, timeout_ms)

Buys one current Ponty listing.

Returns: Promise resolving after the item reaches your inventory and the gold is spent. The result includes the purchased item and cost. It rejects when the listing is gone, you are too far away, you lack gold or inventory space, or the timeout expires.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Pass the listing object returned by get_secondhands(), or pass its rid field. timeout_ms defaults to 10,000ms.

Example:

async function example() { var listings = await get_secondhands(); if (listings.items.length) await buy_secondhand(listings.items[0]); } example();
