send_item(receiver, num, quantity)

Sends a quantity from an inventory slot to a nearby character name or character object.

Returns: Promise resolving with the send response, or rejecting for no_target or another structured failure.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Example:

send_item("Merchant", 0, 10);
