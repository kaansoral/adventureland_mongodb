bet_dice(direction, num, gold, timeout_ms)

Places one tavern dice wager and waits for that wager's roll result.

Returns: Promise resolving with won, roll, wager, payout, net, and edge. A valid bet that loses still resolves with won:false. Invalid bets and timeouts reject.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Use "up", "down", 1 for up, or 2 for down. The server keeps the number inside 0.01 to 99.99 and the wager inside 10,000 to 100,000,000,000 gold. The result timeout defaults to 60,000ms.

Example:

async function example() { var result = await bet_dice("down", 55, 10000); game_log(result.won ? "Won " + result.net : "Lost " + result.wager); } example();
