upload_code(slot_number, slot_name, code_string)

Uploads code text into an account code slot.

Returns: Promise resolving with the API response, or rejecting on API error or the 15-second request timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Use code slots sparingly for code, not as a high-frequency data store.

Example:

upload_code(12, "helpers", "module.exports = {}; ");
