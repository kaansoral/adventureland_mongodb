async wait_for(condition, timeout_ms, interval_ms)

Polls a synchronous or asynchronous condition until it returns a truthy value.

Returns: Promise resolving with the condition's first truthy value. It rejects with invalid_condition, condition_error, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: Defaults are a 10,000ms timeout and 50ms interval. The overall deadline also bounds a condition Promise that never settles. Timeout and interval values below zero are clamped to zero.

Example:

async function example() { var target = await wait_for(function () { return get_nearest_monster({ type: "goo" }); }, 5000, 50); } example();
