accept_friend_request(name)

Accepts a pending friend request and waits for the friendship to be created, rather than stopping at the server's initial acknowledgement.

Returns: Promise resolving with the completed friendship response. It rejects on a server failure, disconnect, or the 15-second completion timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: The temporary socket listeners are removed on every success and failure path.

Example:

accept_friend_request("Wizard").then(function (data) { game_log("Now friends with " + data.name); });
