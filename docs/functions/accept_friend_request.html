accept_friend_request(name, timeout_ms)

Accepts a pending friend request and waits for the friendship to be created, rather than stopping at the server's initial acknowledgement.

Returns: Promise resolving with the correlated friend_complete response. It rejects on an initial or final server failure, disconnect, or timeout.

Promise failures: Unless a function-specific note says otherwise, failures reject with an object containing failed: true and a reason. After mode_resolve_all(), the same failures fulfill instead.

Notes: timeout_ms is optional and defaults to 15000. The legacy friend update remains supported as a success fallback, and temporary socket listeners are removed on every settlement path.

Example:

accept_friend_request("Wizard", 15000).then(function (data) { game_log("Now friends with " + data.name); });
